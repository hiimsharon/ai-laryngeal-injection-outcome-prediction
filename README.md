## 1. 專案範圍與免責聲明

本專案為臨床合作與課程期末專案，目的在於展示人工智慧模型於語音分析之方法設計與實作流程[cite: 1, 45]，**並非正式之臨床研究或經同儕審查之學術發表成果**。本專案僅作為學術展示與技術驗證用途，**不作為任何臨床決策或醫療建議之依據**。

---

## 2. 專案摘要與核心價值 (Research Scope & Highlights)

* **專案名稱**：應用人工智慧方法預測注射式喉成型術後狀況：聲學特徵工程與深度學習時頻圖建模分析
* **核心痛點**：臨床內視鏡檢查僅能得知患者需要手術，但病患術前普遍關注「效果如何、聲音能進步多少、需要使用多少玻尿酸劑量」，傳統上僅能給出籠統的質性回應[cite: 4]。
* **核心價值**：本專案建立一套非侵入式之預測與決策支援框架，結合雙輸入深度學習時頻模型與貝氏最佳化機器學習分類器，實現術後預後（好/不好）之精準預測，具備提升臨床資源利用率與病患溝通品質之潛力[cite: 3, 5, 40]。
